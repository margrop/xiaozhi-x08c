# 设备说明（X08C）

## 基本信息

| 项 | 值 |
| --- | --- |
| 设备 | 小米小爱音箱 X08C |
| 系统 | Android 9 |
| CPU 架构 | ARM32（仅 `armeabi-v7a`） |
| 预装语音助手 | 原厂“小爱同学”（本仓库不修改） |

设备地址统一使用 `<DEVICE_IP>` 占位符。

## 客户端运行形态

应用包名为 `com.xiaozhi.x08c`，通过 ADB 安装。应用启动前台
`VoiceAssistantService`，共享一条麦克风采集链路给 KWS 和 Opus 上行；
`BootReceiver` 支持开机启动。开机启动前必须已经授予麦克风权限。

用户入口是点击“点击说话”或说“小智小智”/“小屁小屁”。“小爱同学”仍由原厂服务处理。

## 麦克风与扬声器

- 录音：16 kHz、单声道、60 ms 帧（960 采样点）；
- 播放：Opus 解码，采样率由服务端 hello 切换；
- 音频自测：约 2 秒本地回环，无需连接服务端；
- KWS：本地 Sherpa-ONNX，不依赖云端唤醒。

## 打断与停止

- TTS 播放时再次说小智关键词会停止本地播放并发送 `abort`；
- “停止 / 打断”按钮结束当前会话；
- 聆听状态下完整识别“关闭”“停止”“结束”“退出”“不用了”“算了”会回时钟；
- “关闭灯”等带目标的指令不会触发退出。

## 已知限制

- 原厂小爱和本服务同时监听时可能有麦克风抢占、回声或音频焦点竞争；
- 首次授予麦克风权限后，若服务已提前启动，可能需要重开应用；
- 服务端本地 ASR 在 VAD 断句后给出完整文本，不是逐字实时字幕；
- 目标是本地侧载设备，不是 Google Play 发布，`targetSdk 28` 是有意配置。

ADB 开启、备份和设备辅助脚本见 `tools/` 下对应说明。修改分区前必须先备份。
